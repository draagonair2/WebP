HTML5 기본 태그와 웹 페이지 구성

이번 장에서는 HTML5를 이용하여 웹 페이지의 기본 구조를 만들고, 텍스트와 이미지, 목록, 표, 하이퍼링크, 인라인 프레임, 오디오와 비디오 등을 웹 페이지에 삽입하는 방법을 학습하였다. HTML은 웹 페이지의 내용을 구성하는 가장 기본적인 언어이며, 다양한 태그를 조합하여 원하는 형태의 웹 페이지를 만들 수 있다. 이번 장의 주요 학습 목표도 HTML5 기본 문서 작성과 이미지, 표, 하이퍼링크, 인라인 프레임 및 미디어 삽입에 있다.

HTML5 문서는 <!DOCTYPE html>로 HTML5 문서임을 알리는 것에서 시작한다. 이후 <html> 태그 안에 <head>와 <body>를 작성한다. <head>에는 문서의 제목, CSS 스타일, 자바스크립트, 메타데이터 등이 들어가고 <body>에는 사용자가 실제로 볼 수 있는 텍스트, 이미지, 표, 동영상 등의 내용이 작성된다. 따라서 웹 페이지를 만들 때 가장 먼저 이러한 기본 구조를 정확하게 작성하는 것이 중요하다.

본문을 작성할 때는 목적에 따라 여러 가지 태그를 사용할 수 있다. <h1>부터 <h6>까지는 문단의 제목을 작성할 때 사용하며 숫자가 작을수록 더 큰 제목으로 나타난다. 또한 <p>는 하나의 단락을 만들고 <br>은 줄바꿈, <hr>은 수평선을 표시할 때 사용한다. 텍스트를 꾸미기 위해서는 <b>, <strong>, <em>, <i>, <small>, <del>, <ins>, <sup>, <sub>, <mark> 등의 태그를 사용할 수 있다. 이러한 태그를 이용하면 중요한 글자를 강조하거나 삭제선, 윗첨자, 아래첨자 등의 표현도 가능하다.

HTML 태그는 블록 태그와 인라인 태그로도 구분할 수 있다. <p>, <h1>, <div>, <ul> 등은 블록 태그로 새로운 줄에서 시작하며 한 줄을 하나의 영역처럼 사용한다. 반면 <strong>, <a>, <img>, <span> 등은 인라인 태그로 문장이나 블록 내부의 일부분으로 사용된다. 대표적으로 <div>는 큰 영역을 묶는 데 사용하고 <span>은 문장 중 특정 부분을 묶을 때 사용할 수 있다.

HTML에서는 키보드로 직접 입력하기 어렵거나 HTML 문법에서 특별한 의미를 가지는 문자도 표현할 수 있다. 이를 위해 엔터티 또는 문자 코드가 사용된다. 예를 들어 <는 &lt;, 저작권 기호인 ©는 &copy;로 표현할 수 있다. HTML5에서는 UTF-8과 유니코드 문자 체계를 이용하여 다양한 문자와 기호를 사용할 수 있다.

웹 페이지에 이미지를 넣을 때는 <img> 태그를 사용한다. 이미지 파일의 위치는 src 속성으로 지정하며 필요에 따라 이미지의 크기나 대체 문자를 설정할 수 있다. 이미지 파일을 HTML 파일 아래의 별도 폴더에 저장하여 상대 경로로 불러오는 방법도 사용할 수 있다. 이를 통해 텍스트만 있는 페이지보다 다양한 내용을 표현할 수 있다.

여러 항목을 정리할 때는 리스트를 사용한다. 순서가 없는 목록은 <ul>, 순서가 있는 목록은 <ol>을 사용하고 각각의 항목은 <li>로 작성한다. 또한 용어와 그에 대한 설명을 표현할 때는 <dl>을 이용할 수 있다. 리스트 안에 다른 리스트를 넣는 중첩 리스트도 가능하므로 메뉴나 목차처럼 계층이 있는 내용을 표현할 때 유용하다.

데이터를 행과 열 형태로 표현할 때는 <table> 태그를 사용한다. <caption>은 표의 제목을 나타내며 <tr>은 하나의 행, <th>는 제목 셀, <td>는 일반 데이터 셀을 의미한다. 또한 <thead>, <tbody>, <tfoot>을 사용하면 표의 헤더, 본문, 바닥 부분을 구분할 수 있다. 표 안의 <td>에 이미지를 넣는 것도 가능하다.

웹의 중요한 기능 중 하나인 하이퍼링크는 <a> 태그를 사용하여 작성한다. href 속성에 이동할 주소를 지정하면 같은 사이트의 다른 페이지뿐 아니라 외부 웹 사이트로도 이동할 수 있다. 텍스트뿐만 아니라 이미지에도 하이퍼링크를 설정할 수 있다. 또한 id와 href="#아이디"를 이용하면 같은 페이지 안에서 원하는 위치로 바로 이동할 수 있다. 이는 목차가 있는 긴 문서에서 특히 유용하다.

<iframe>은 현재 웹 페이지 안에 다른 HTML 페이지를 삽입할 때 사용하는 태그이다. src 속성으로 표시할 웹 페이지를 지정하고 width와 height를 사용하여 프레임의 크기를 설정할 수 있다. 여러 개의 iframe을 하나의 페이지에 삽입할 수도 있으며, 링크의 target 속성과 결합하여 특정 프레임에 새로운 페이지를 출력하는 방식으로도 활용할 수 있다.

마지막으로 HTML5에서는 <audio>와 <video> 태그를 이용하여 별도의 플러그인 없이 음악과 동영상을 웹 페이지에서 재생할 수 있다. controls 속성을 사용하면 재생 및 정지 등의 조작 버튼을 표시할 수 있고 <source>를 여러 개 작성하여 브라우저가 지원하는 파일 형식을 선택하도록 할 수도 있다. 다만 최신 브라우저에서는 보안상의 이유로 자동 재생이 제한될 수 있어 사용자가 직접 재생 버튼을 눌러야 하는 경우가 있다.

이번 장을 학습하면서 HTML은 단순히 글자를 화면에 출력하는 언어가 아니라 여러 종류의 태그와 속성을 조합하여 하나의 웹 페이지를 구조적으로 구성하는 언어라는 점을 알게 되었다. 특히 이미지, 표, 링크, 오디오와 비디오처럼 서로 다른 형태의 콘텐츠도 기본적인 HTML 태그만으로 웹 페이지에 표현할 수 있다는 점이 중요하다고 생각한다. 앞으로 CSS와 자바스크립트를 함께 사용하면 이번 장에서 만든 기본적인 HTML 구조를 바탕으로 더욱 보기 좋고 다양한 기능을 가진 웹 페이지를 만들 수 있을 것이다.
