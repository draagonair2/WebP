이번 장에서는 HTML5 문서의 기본 구조부터 이미지, 리스트, 표, 하이퍼링크, iframe, 오디오와 비디오 삽입까지 웹 페이지를 구성하는 기본 요소들을 다뤘다. 실습을 하면서 단순히 태그 이름을 외우는 것보다 각 태그가 어떤 역할을 하고, 어떤 상황에서 사용되는지를 이해하는 것이 더 중요하다고 느꼈다. 특히 img 태그로 이미지를 불러오고, ul이나 ol을 이용해 목록을 구성하고, table을 이용해 데이터를 정리하는 과정을 통해 HTML이 화면의 구조를 만드는 언어라는 점을 알 수 있었다.

하이퍼링크 부분에서는 a 태그의 href 속성을 이용해 다른 페이지로 이동하는 방법뿐만 아니라 id를 이용해 같은 페이지 안의 특정 위치로 이동하는 방식도 배웠다. 또한 iframe을 이용해 현재 페이지 안에 다른 웹 페이지를 불러올 수 있었고, audio와 video 태그를 사용해 별도의 프로그램 없이도 웹 페이지에서 미디어를 재생할 수 있다는 점도 확인했다.

전체적으로 이번 장은 앞으로 CSS나 JavaScript를 배우기 전에 필요한 HTML의 기본 구조와 문법을 익히는 과정이라고 생각한다. 예제 자체는 크게 어렵지 않았지만 직접 코드를 입력하고 브라우저에서 결과를 확인하면서 태그와 속성의 관계를 이해하는 데 도움이 됐다. 앞으로는 단순히 예제를 따라 작성하는 것에서 그치지 않고, 필요한 요소를 직접 조합해서 하나의 페이지를 구성하는 연습도 더 해보고 싶다.
