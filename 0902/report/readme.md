웹 프로그래밍 1장 학습 리포트
웹의 기본 구조와 HTML5의 이해

이번 1장을 학습하면서 가장 중요하게 이해한 것은 웹이 어떤 구조로 동작하는지와 HTML, CSS, JavaScript가 각각 어떤 역할을 담당하는지였다. 이전에는 인터넷과 웹을 거의 같은 개념으로 생각했지만, 인터넷은 여러 컴퓨터가 연결된 네트워크이고 웹은 그 인터넷을 이용하여 정보를 전달하고 공유하는 서비스 중 하나라는 차이를 알게 되었다. 즉 인터넷이 정보를 전달할 수 있는 기반이라면 웹은 그 위에서 동작하는 하나의 서비스라고 볼 수 있다.

웹의 기본 구조는 웹 클라이언트와 웹 서버의 관계로 이해할 수 있었다. 사용자가 Chrome과 같은 브라우저를 통해 웹페이지를 요청하면 서버는 필요한 HTML 문서나 이미지 등의 데이터를 전송한다. 이후 서버가 보낸 HTML을 실제 화면으로 해석하여 보여주는 것은 브라우저의 역할이다. 처음에는 서버가 완성된 화면 자체를 보내주는 것으로 생각했지만, 학습하면서 클라이언트의 요청 → 서버의 처리 및 응답 → 브라우저의 해석과 출력이라는 과정으로 동작한다는 것을 이해했다. 브라우저와 서버가 이러한 데이터를 주고받을 때 사용하는 대표적인 통신 규칙이 HTTP이다.

웹페이지의 주소인 URL도 하나의 문자열이 아니라 여러 구성 요소로 이루어져 있다는 것을 배웠다. 예를 들어 http://www.oracle.com:80/technetwork/java/index.html에서는 http가 프로토콜, www.oracle.com이 서버 주소, 80이 포트 번호이며 /technetwork/java/는 경로명, index.html은 웹페이지 파일 이름에 해당한다. 이를 통해 브라우저에 URL을 입력하는 행동은 단순히 사이트 이름을 입력하는 것이 아니라 어떤 방식으로 통신하여 어느 서버의 어떤 파일을 요청할 것인지 지정하는 과정이라는 점을 이해할 수 있었다.

이번 장에서 실습과 가장 직접적으로 연결된 내용은 HTML, CSS, JavaScript의 역할 구분이었다. HTML은 웹페이지의 구조와 내용을 만들고, CSS는 색상·크기·정렬·배경과 같은 모양을 담당하며, JavaScript는 사용자의 행동에 따라 웹페이지가 변화하도록 만드는 역할을 한다. 이를 간단히 정리하면 HTML은 ‘무엇이 있는가’, CSS는 ‘어떻게 보이는가’, JavaScript는 ‘어떻게 동작하는가’를 결정한다고 볼 수 있다.

특히 JavaScript 예제를 직접 작성하면서 이 구분을 더 명확하게 이해할 수 있었다. <img id="fig" src="">에서 id는 HTML 요소를 구분하기 위한 이름처럼 사용되고, JavaScript의 document.getElementById("fig")를 이용하면 해당 요소를 찾아올 수 있다. 이후 이미지의 src에 사진 파일을 지정하면 사진이 나타나고, src=""로 변경하면 사진이 사라진다. 여기에 onmouseover와 onmouseout을 사용하면 이름 위에 마우스를 올렸을 때 사진을 나타내고, 마우스를 내렸을 때 다시 숨기는 기능을 구현할 수 있었다. 이 실습을 통해 JavaScript는 새로운 화면을 만드는 것뿐만 아니라 이미 존재하는 HTML 요소를 찾아 그 상태를 변화시키는 역할도 한다는 점을 이해할 수 있었다.

웹 서버 부분에서는 Apache, IIS, nginx와 같은 웹 서버 소프트웨어와 검색·회원 관리 등의 실제 기능을 수행하는 웹 서버 응용프로그램을 구분하였다. 웹 서버 소프트웨어는 브라우저의 요청을 해석하고 필요한 응용프로그램을 작동시킨 뒤 결과를 브라우저로 전달하며, 웹 서버 응용프로그램은 웹사이트의 목적에 맞는 실제 기능을 처리한다. 두 개념이 처음에는 비슷하게 느껴졌지만, 하나는 요청을 전달하고 관리하는 역할이고 다른 하나는 실제 업무를 수행하는 프로그램이라고 구분하니 이해하기 쉬웠다.

마지막으로 HTML5가 등장한 배경도 중요한 내용이었다. 과거에는 Active-X, Flash, 플러그인 등 비표준 기술이 혼재하여 브라우저 사이의 호환성 문제가 있었고, 스마트폰과 태블릿처럼 인터넷을 사용하는 기기가 다양해지면서 기존 PC 중심의 웹 방식에는 한계가 생겼다. 이에 따라 여러 기기와 환경에서 공통으로 사용할 수 있는 새로운 웹 표준이 필요해졌고 HTML5가 등장하였다.

이번 장을 통해 웹페이지 하나가 화면에 나타나는 과정에는 서버, 클라이언트, HTTP, URL, HTML, CSS, JavaScript가 서로 연결되어 있다는 점을 이해할 수 있었다. 특히 코드를 단순히 외우기보다 각 코드가 전체 웹 구조에서 어떤 역할을 하는지 생각하면서 학습하는 것이 이후 웹 프로그래밍 내용을 이해하는 데 더 중요하다고 느꼈다.
