# WebP# CSS3를 이용한 웹 페이지 꾸미기

이번 장에서는 HTML로 만든 웹 페이지에 CSS3를 적용해 색상, 글꼴, 배경, 테두리와 같은 화면의 모양을 직접 꾸미는 방법을 학습했다. 이전까지 HTML을 이용해 웹 페이지의 내용과 구조를 만드는 데 집중했다면, 이번에는 같은 HTML 문서라도 CSS를 어떻게 작성하느냐에 따라 화면이 크게 달라질 수 있다는 것을 실습을 통해 확인할 수 있었다. HTML이 웹 페이지의 기본적인 구조를 담당한다면 CSS는 그 구조가 실제 화면에서 어떻게 보일지를 결정하는 역할을 한다고 이해할 수 있었다.

먼저 CSS 스타일을 HTML에 적용하는 여러 가지 방법을 배웠다. `<style>` 태그 안에 CSS를 작성하는 방법, HTML 태그의 `style` 속성에 직접 작성하는 방법, CSS를 별도의 파일로 만든 뒤 `<link>`나 `@import`를 사용해 불러오는 방법이 있었다. 처음에는 `<link>`와 `@import`가 비슷해 보여 헷갈렸지만, `<link>`는 HTML에서 외부 CSS 파일을 연결하는 태그이고 `@import`는 CSS에서 다른 CSS 파일을 불러오는 문법이라는 차이를 알게 되었다. 특히 외부 CSS 파일을 사용하면 HTML과 디자인 코드를 분리할 수 있어 코드가 더 깔끔해지고 여러 페이지에 같은 디자인을 적용하기도 편리하다는 점을 이해했다.

이번 장에서 가장 중요하게 다룬 부분 중 하나는 셀렉터였다. 셀렉터는 CSS를 어떤 HTML 요소에 적용할지를 지정하는 부분이다. `p`, `h3`, `span`과 같이 태그 이름을 그대로 사용하는 태그 이름 셀렉터부터 `class`와 `id`를 이용하는 방법까지 실습했다. 예를 들어 `.help`처럼 점으로 시작하면 같은 `class`를 가진 여러 요소에 스타일을 적용할 수 있고, `#hot`처럼 `#`으로 시작하면 특정 `id`를 가진 요소를 선택할 수 있었다. 단순히 셀렉터 문법을 외우는 것보다 "어떤 요소를 선택해서 꾸미고 싶은가"를 먼저 생각하는 것이 더 중요하다는 느낌을 받았다.

또한 셀렉터를 서로 조합하여 더 구체적인 요소를 선택하는 방법도 배웠다. 특정 영역 안에 있는 `strong` 태그만 선택하거나, 특정 `id`를 가진 요소의 자손만 꾸미는 식으로 조건을 세분화할 수 있었다. HTML 문서가 복잡해지면 모든 요소에 별도의 스타일을 작성하는 것보다 이러한 셀렉터의 관계를 잘 이용하는 것이 훨씬 효율적일 것이라고 생각했다.

실습에서는 색상과 텍스트를 꾸미는 여러 CSS 속성도 사용했다. `color`로 글자색을 변경하고 `background-color`로 배경색을 지정했으며, 색 이름뿐만 아니라 `#A52A2A`와 같은 16진수 색 코드도 사용할 수 있다는 것을 확인했다. `font-family`, `font-size`, `text-align`, `text-indent`, `text-decoration` 등의 속성을 사용하면서 글자의 크기와 글꼴뿐 아니라 정렬, 들여쓰기, 밑줄과 같은 세부적인 부분도 CSS에서 제어할 수 있다는 것을 배웠다.

특히 `:hover`를 사용한 실습이 기억에 남았다. 일반 상태에서는 초록색이고 밑줄이 없는 링크에 마우스를 올렸을 때 violet 색과 밑줄이 나타나도록 만들었고, 카드의 뒷면 이미지에 마우스를 올리면 앞면 이미지로 바뀌도록 만들었다. 단순히 고정된 디자인만 만드는 것이 아니라 사용자의 행동에 따라 화면의 모습이 변하도록 할 수 있다는 점에서 CSS만으로도 어느 정도의 상호작용을 구현할 수 있다는 것을 알게 되었다.

박스 모델에 대해서도 학습했다. HTML의 각 요소는 화면에서 하나의 사각형 박스로 취급되며, 그 박스는 실제 내용이 들어가는 콘텐츠 영역을 중심으로 `padding`, `border`, `margin`으로 구성된다. 이전에는 여백을 단순히 공간을 띄우는 기능 정도로 생각했지만, `padding`은 내용과 테두리 사이의 안쪽 공간이고 `margin`은 테두리 바깥쪽의 공간이라는 차이를 구분하게 되었다. 이미지에 15px 크기의 테두리를 만들고 5px의 padding을 주는 실습을 통해 이러한 박스 구조를 실제 결과로 확인할 수 있었다.

또한 `background-image`를 이용해 요소의 배경에 이미지를 넣거나 `border-image`를 이용해 일반적인 선 대신 이미지를 테두리로 사용하는 방법도 실습했다. 처음에는 이미지라면 무조건 `<img>` 태그를 사용한다고 생각했지만, CSS에서 이미지를 배경이나 테두리의 일부로도 사용할 수 있다는 점이 흥미로웠다. 같은 이미지라도 HTML의 콘텐츠로 삽입하는 것과 CSS에서 디자인 요소로 사용하는 것은 목적이 다르다는 점도 조금씩 구분할 수 있게 되었다.

이번 장을 공부하면서 CSS는 단순히 웹 페이지에 색을 입히는 기능만 담당하는 것이 아니라, 원하는 요소를 정확하게 선택하고 각 요소의 크기, 위치, 글자, 배경, 테두리, 사용자 반응까지 세밀하게 조정하는 언어라는 것을 알게 되었다. 특히 오늘 실습에서는 셀렉터를 직접 작성하고 `class`, `id`, `:hover`, 배경 이미지, 테두리 등을 하나씩 적용해 보면서 CSS 코드와 실제 브라우저 화면이 어떻게 연결되는지 이해하는 데 도움이 되었다. 앞으로 더 복잡한 웹 페이지를 만들 때는 단순히 속성을 외우기보다는 HTML의 구조를 먼저 파악하고, 그 구조에 맞는 셀렉터와 스타일을 선택하는 방식으로 작성하는 것이 중요할 것 같다.
