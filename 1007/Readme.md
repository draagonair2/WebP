# 6장 자바스크립트 언어

이번 6장에서는 자바스크립트의 기본 문법과 사용 방법을 학습했다. 이전까지는 HTML을 이용해 웹 페이지의 구조를 만들고 CSS로 디자인을 꾸미는 방법을 배웠다면, 이번에는 자바스크립트를 이용해 웹 페이지에 실제 동작을 추가하는 방법을 배웠다. 자바스크립트를 사용하면 사용자의 입력을 받거나 계산을 수행할 수 있고, 마우스 움직임에 따라 이미지나 배경색을 변경하는 것도 가능하다는 것을 알게 되었다.

먼저 자바스크립트 코드를 HTML 문서에 작성하는 방법을 배웠다. HTML 태그의 이벤트 리스너 속성에 직접 코드를 작성하거나 `<script>` 태그 안에 작성할 수 있으며, 별도의 `.js` 파일을 만들어 불러오는 방법도 있었다. 실습문제 1번에서는 마우스를 올리면 배경색이 노란색으로 바뀌고, 마우스를 내리면 원래 색으로 돌아오는 기능을 구현했다. 이 과정에서 `onmouseover`, `onmouseout` 이벤트와 `function`을 사용하는 방법을 익혔다. 처음에는 `this`와 `obj`의 차이가 헷갈렸지만, `this`는 현재 HTML 요소를 가리키고 `obj`는 함수에 전달된 요소를 받아 사용하는 매개변수라는 점을 이해할 수 있었다.

자바스크립트를 이용해 화면에 내용을 출력하고 사용자에게 입력받는 방법도 배웠다. `document.write()`를 사용하면 웹 페이지에 문자뿐 아니라 HTML 태그도 출력할 수 있었다. 실습문제에서는 이를 이용해 환영 문구를 출력하고, 별 문자를 한 줄씩 증가시키거나 숫자와 제곱값을 표로 만드는 연습을 했다. 또한 `alert()`는 메시지를 보여주고, `prompt()`는 사용자의 입력을 받으며, `confirm()`은 확인과 취소를 선택할 수 있게 한다는 차이도 알게 되었다.

다음으로 변수와 데이터 타입, 연산자를 학습했다. 자바스크립트에서는 `var`, `let`, `const`를 이용해 변수를 선언할 수 있으며, 특히 `let`은 값을 변경할 수 있고 `const`는 선언한 변수에 다른 값을 다시 대입할 수 없다는 점을 배웠다. 숫자, 문자열, 논리값 등의 데이터 타입과 함께 산술 연산자, 비교 연산자, 논리 연산자, 비트 연산자도 살펴보았다. 특히 문자열과 숫자를 `+` 연산자로 연결하면 일반적인 덧셈과 다른 결과가 나올 수 있다는 점이 기억에 남았다.

조건문에서는 `if`, `else if`, `else`, `switch`를 사용해 조건에 따라 서로 다른 코드를 실행하는 방법을 배웠다. 실습문제 4번에서는 `prompt()`로 요일을 입력받고, 입력한 요일에 따라 출근 또는 휴일을 출력하도록 만들었다. 여러 조건을 구분해야 할 때 `switch`문을 사용하면 코드를 비교적 간단하게 작성할 수 있었고, `break`를 사용하지 않으면 다음 `case`의 코드까지 실행될 수 있다는 점도 이해했다.

반복문에서는 `for`, `while`, `do-while`을 학습했다. `for`문은 반복 횟수가 정해진 작업에 사용하기 편리했고, `while`문은 조건이 참인 동안 코드를 반복하도록 만들 수 있었다. `do-while`은 조건을 검사하기 전에 코드를 먼저 한 번 실행한다는 특징이 있었다. 실습문제 5번에서는 올바른 암호를 입력할 때까지 입력창을 반복해서 띄우는 프로그램을 만들었다. 또한 중첩 `for`문을 이용해 별의 개수를 한 개씩 늘려 출력하면서 반복문이 어떤 순서로 실행되는지 확인할 수 있었다.

함수를 만드는 방법도 배웠다. `function`으로 함수를 선언하고 매개변수를 통해 값을 전달받으며, `return`으로 실행 결과를 돌려줄 수 있었다. 실습문제 6번에서는 두 수 중 더 큰 수를 반환하는 함수와 특정 문자를 정해진 횟수만큼 출력하는 함수를 작성했다. 이전에는 함수를 단순히 여러 코드를 묶어놓은 것으로 생각했지만, 직접 사용해 보니 같은 작업을 반복할 때 코드를 다시 작성하지 않아도 된다는 장점이 있다는 것을 알게 되었다.

실습문제 7번에서는 입력한 정수의 가장 높은 자리 숫자와 가장 낮은 자리 숫자를 비교하는 프로그램을 작성했다. `% 10` 연산으로 마지막 자리 숫자를 구하고, `Math.floor()`와 `while`문을 이용해 첫 번째 자리 숫자를 구하는 방식이었다. 문자열로 변환하지 않고도 숫자의 각 자릿수를 계산할 수 있다는 점을 배웠다. 마지막 8번에서는 `eval()`을 이용해 입력한 수식을 계산하는 프로그램을 작성했고, `parseInt()`를 이용한 문자열의 정수 변환과 `isNaN()`을 이용한 숫자 판별 방법도 함께 익혔다. 다만 `eval()`은 일반 자바스크립트 코드도 실행할 수 있으므로 실제 웹사이트에서 사용자 입력을 그대로 전달하는 것은 위험하다는 점도 알아둘 필요가 있다.

Open Challenge 06에서는 지금까지 배운 내용을 종합하여 사용자에게 양의 정수를 입력받고, 해당 숫자만큼 별을 증가시키며 출력하는 프로그램을 작성했다. `printStar()` 함수를 직접 만들고 중첩 반복문으로 별을 출력했으며, 잘못된 값이 입력되었을 때 오류 메시지를 출력하는 조건도 추가했다. 이 문제에서는 단순히 별을 출력하는 것보다 사용자가 입력한 값이 올바른지 확인하고, 조건에 따라 함수를 실행하도록 만드는 과정이 중요했다.

이번 장을 통해 자바스크립트의 기본적인 문법을 배우면서 HTML, CSS, JavaScript가 각각 어떤 역할을 하는지 조금 더 명확하게 이해할 수 있었다. 특히 수업에서 배운 변수와 조건문, 반복문, 함수를 실제 웹 페이지에 적용해 보니 이전에 다른 프로그래밍 언어에서 배웠던 개념들이 웹 프로그래밍에서도 비슷하게 사용된다는 것을 알 수 있었다. 아직 조건문과 반복문이 복잡하게 연결된 코드는 한 번에 이해하기 어렵지만, 코드를 한 줄씩 따라가며 실행 결과를 확인하는 방식으로 연습하면 익숙해질 수 있을 것 같다. 앞으로는 자바스크립트를 이용해 버튼이나 입력창이 실제로 동작하는 웹 페이지를 직접 만들어 보고 싶다.
